## 3. 시장(market) 탭
- [ ] 상단 **시장 상태 바**(KOSPI/KOSDAQ/ADR/나스닥) 표시
- [ ] **수급 현황** 패널(외국인·기관) 표시 (데이터 있을 때)
- [ ] **오늘 강세 섹터** 표시 (데이터 있을 때)
- [ ] **섹터 동향** — 장중=거래대금/시장지도 토글, 장외=시장지도
- [ ] 서브탭 strip(**수급 / 시장타이밍 / 뉴스 / 글로벌**) 노출, 기본 **수급**
  - [ ] 수급 → InvestorAnalysisPage 임베드 정상
  - [ ] 시장타이밍 → MarketTimingPage 임베드 정상
  - [ ] 뉴스 → NewsPage 임베드 정상
  - [ ] 글로벌 → **GlobalFuturesPage 임베드** 정상 (아래 §6)
- [ ] 발굴 전용 블록(추천/저평가/차트신호)이 **시장 탭엔 안 보임**

## 4. 발굴(discover) 탭
- [ ] **종합 추천 TOP** 표시, 등급 범례 표시
- [ ] **저평가 TOP 10** 표시
- [ ] **시간대별 신호 / 실시간 급증(LiveSurge)** — 장중=LiveSurge, 장전·장후=today-signals
- [ ] **차트 신호 종목** 표시 (패턴 있을 때) + 필터(전체/상승/신뢰도)
- [ ] 장중: 추천 카드 #1~5에 **실시간 추적 점(rec-live-dot)** 표시 (currentPhaseKey==='during')
- [ ] 서브탭 strip(**종합 / AI전략 / 백테스트 / 스크리너 / 퀀트TA**), 기본 AI전략
  - [ ] 각 서브탭 임베드 페이지 정상 렌더
- [ ] 시장 전용 블록(상태바/수급/섹터)이 **발굴 탭엔 안 보임**

## 5. 매매(trade) 탭
- [ ] **ADMIN**: PaperTradingPage(봇/페이퍼/성과) 임베드 정상
- [ ] **일반 USER**: "관리자 전용입니다" 안내만 노출 (봇 데이터 비노출)
- [ ] 매매 탭에서는 **라이브 폴링/freshness 바 미동작**(isLiveTab=false) — 불필요 갱신 없음

- [ ] `/global-futures` 직접 진입(독립 라우트): **자체 GlobalNav/GNB 노출** + 정상 동작(딥링크 보존)
- [ ] `/gold` `/silver` `/oil` → `/global-futures` redirect 동작

## 7. 폴링 / 데이터 신선도 / 탭 숨김 (불변식 보존)
- [ ] **장중** 시장·발굴 탭: 60초 주기 자동 갱신 + freshness 바 카운트다운(60→0) 동작
- [ ] 수동 갱신 버튼 동작
- [ ] **브라우저 탭 숨김(다른 탭 이동) → 폴링/카운트다운 정지**, 복귀 시 즉시 1회 갱신
- [ ] 매매 탭에 있을 땐 폴링 미발생(네트워크 탭으로 60초간 추천/시장 API 호출 없음 확인)
- [ ] 초기 진입 시 **스태거 로딩 순서 유지**: 시장맵 먼저 → ~500ms 후 AI전략 → ~1.2s 후 뉴스
      (network 탭 타임라인으로 동시 폭주 없는지 확인)

## 8. 종목 상세 — 요약/근거/심화 3섹션
- [ ] **요약존**: 헤더(시세·단기/중장기 점수) → 결론카드 → **핵심요약 바(QuickSummaryBar)** 순서로 상단 노출
- [ ] **근거존**: 행동권고 헤드라인 → 리스크 카드 → main-grid(차트·재무·수급·AI)
- [ ] **심화존**: "🔬 심화 분석" 섹션 **기본 접힘** 상태로 표시
  - [ ] 토글 클릭 → 펼침: Peer 비교 / 볼륨프로파일 / 지지·저항 / 관련종목 / 차트패턴 노출 (Peer 가 main-grid 아닌 심화존)
  - [ ] 다시 클릭 → 접힘
- [ ] **접힘 상태에서도 보조 데이터가 정상 로드**(펼치면 즉시 채워져 있음 = 마운트 유지 확인;
      펼친 뒤에야 로딩 스피너가 도는 게 아니어야 함)
- [ ] 상세 10초 자동 갱신 토글 동작(useAutoRefresh) — 켜고 끄기, 갱신 시각 표시
- [ ] 투자자 동향 / 트레이딩 지표 탭 정상
