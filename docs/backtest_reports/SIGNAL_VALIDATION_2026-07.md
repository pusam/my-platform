## 권고 (산식 변경은 전부 별도 세션에서 사람이 결정)

1. **기술**: 임계 게이트(≥13) **유지**. 연속 점수 가중 강화는 근거 없음(Spearman 0.02).
2. **수급**: composite 캡(10, P1-6) **유지** — Phase 1·2 모두 강세(≥15)가 약세보다 나쁨을 재확인.
   `scoreSupplyDemand` 를 금액 중심 → **연속일(streak5) 반영으로 재설계할 가치는 있음**(후보 과제) —
   단 streak5 도 alpha 음수라 기대치를 낮게, `SignalWeeklyReportService` 주간 데이터와 교차 확인 후.
3. **실적·섹터테마**: **미측정 상태를 명시적으로 유지**(§4c — 미측정을 "문제없음"으로 위장하지 않는다).
   운영 `RecommendationSnapshot` 보존이 7일이라, 측정하려면 주기적 CSV export
   (`GET /api/admin/backtest-export/recommendation-snapshots`) 축적이 선행되어야 함.
4. **청산 규칙**: ATR×2.0~2.5 가 유의한 개선 후보 — 곧바로 봇 교체가 아니라
   **① 모의(VIRTUAL) 모드에서 ATR 청산 병행 측정 → ② 운영 신호셋(total≥55)으로 재검증**(스냅샷 CSV 확보 후)의
   2단계 검증을 권고. 개별 손실 확대(-5% 초과 35%)를 감내할지는 운영자 위험선호 판단.
5. **RVOL(V41)**: 이번에 스냅샷 축적을 시작했으므로, n 이 쌓이면 "RVOL 밴드 × 적중률" 조건부 집계를
   `accuracy-by-band` 패턴으로 추가 검증(승격 조건 동일 — 데이터 검증 전 산식 미편입).
