# §4e 유튜브 참고 의견

> 2026-11-11 에 옛 `CLAUDE.md` 에서 글자 그대로 옮긴 경위 원문이다. **지킬 규칙은 `CLAUDE.md` §4e 의 규칙 줄에 있다** — 이 문서는 '왜'를 위한 것이다.
> 번호(예: `§4c.13`)는 옛 `CLAUDE.md` 의 절과 그 절 안 항목 순서다(하위 항목은 `§7.8-2`). 문단 안의 '위·아래 항목'은 이 순서를 가리킨다 — 전체 순서표는 `docs/rules/README.md`.
> 번호 제목 바로 아래의 '정정(날짜): …' 줄은 옮긴 뒤 붙인 것이다(문단은 손대지 않았다).
> 사실이 바뀌면 문단을 고치거나 정정 줄을 붙이고, `CLAUDE.md` 의 같은 번호 규칙 줄도 같이 고친다. `AGENTS.md` 는 `CLAUDE.md` 의 사본이고, 이 문서는 두 쪽이 같이 읽는다.

#### §4e.2

- **자동 수집은 연결하지 않았다(의도)**: 공개 영상 자막은 YouTube Data API 로 못 받는다(`captions.download` 는 영상 편집 권한 필요, `captions.list` 는 본문 없음). 비공식 스크래핑은 약관 문제라 붙이지 않았다. **서버는 영상 페이지·자막을 가져오지 않는다** — URL 은 영상 ID 추출에만 쓴다(`YoutubeUrlParser`, 허용 호스트·경로만). 제목으로 내용을 추측하는 경로를 만들지 말 것. 자동 제공자를 붙이면 `uploadTranscript` 와 같은 적재 경로(자막 → 분석 실행)로 들어오게 한다.

#### §4e.3

- **불변식**: ① 추천 점수·순위·BUY·손절/익절·봇·`signal_outcome`·`stock_catalyst` 와 섞지 않는다 — `YoutubeOpinionIsolationTest` 가 패키지 밖 참조 0 건을 **바이트코드로** 고정한다(의견 점수 가산·인물 순위·텔레그램 자동 발송은 범위 밖). ② **모델 출력을 믿지 않는다** — 근거 발췌가 자막 원문에 없거나 종목 표기가 발언 근처(앞뒤 한 줄) 자막에 없으면 검토, 조건이 붙은 긍정·부정은 CONDITIONAL 로 낮추고(반대 방향 변환 금지 — "조정하면 매수"는 지금 매수가 아니다), 목표가·기간은 원문에 있을 때만(없으면 null), 발언자는 자막 표기 또는 단독 출연자일 때만(모델이 댄 이름으로 정하지 않는다), 종목은 마스터로 확인된 것만(동명·ASR 오류·코드 불일치는 검토). 집계는 CURRENT_VIEW 만 — 인용·과거 회고·단순 언급은 기록만. ③ 집계 창은 **영상 게시 시각** 7일, **인물 수 ≠ 발언 수**, 같은 사람이 창 안에서 입장을 바꾸면 MIXED(순서 보존), 발언자 미상은 인물 수 제외, 재업로드(`duplicate_of`)·지난 실행·검토 대기/거절 제외. 조회 실패(`dataAvailable=false`)·분석된 영상 없음·분석했지만 언급 없음·의견 있음을 다른 상태로 말한다(§4c). ④ 재분석은 새 실행과 그 실행의 발언 행을 만든다 — 화면은 `yt_video.current_run_id` 만 읽어 중복이 없고 지난 행이 이력이다. **실패한 재분석은 `current_run_id` 를 바꾸지 않는다**(이전 결과 유지 + 실패 사유 표시, 청크 하나라도 실패하면 발언을 하나도 저장하지 않는다). 사람 검토 결정(승인·거절·수동 종목)은 **발언 식별과 결정 승계를 나눠** 잇는다(2026-09-29, `ReviewCarryOver` 순수 함수) — `statement_key`(영상·종목·발언자·시작 줄·유형)는 '같은 발언인가'만 답하고, 결정은 사람이 본 **내용 지문**(요약·근거 설명·의견·유형·조건·기간·목표가·근거 발췌·발언자·종목 표기·위치 초·**그 구간의 자막 원문**)이 같을 때만 잇는다. 승인은 여기에 더해 **새 검토 사유가 없을 때만**(사유가 줄어든 건 괜찮다) 잇는다. **사람이 결정한 발언이 바뀌면 NEEDS_REVIEW** — 이번 검증에 걸릴 게 없어도 자동 통과시키지 않는다(승인이면 `REVIEW_NOT_CARRIED`, 수동 종목도 버린다 / 거절이면 `PREVIOUSLY_REJECTED`). **키가 달라진 경우**(모델이 시작 줄을 다르게 잡음·종목이나 발언자가 바뀜)도 같다 — 직전 실행의 사람 결정 중 이번 실행에 같은 키의 후속이 없는 것('남겨진 결정')과 시간이 겹치면 NEEDS_REVIEW(종목·발언자는 따지지 않는다 — 그게 바뀌어 키가 달라졌을 수 있다, 경계만 닿는 이웃은 제외). **자동 통과(AUTO_OK)는 사람 검토를 받은 적 없는 발언의 규칙이다** — 새 발언, 직전에 자동 통과·검토 대기였던 발언은 바뀌어도 이번 검증 결과 그대로. 인용·언급처럼 원래 화면에 안 나가는 유형은 상태를 바꾸지 않고 표시만 남긴다. 자막 버전은 번호가 아니라 **구간 원문**으로 비교한다 — 무관한 줄만 고친 자막은 다시 검토시키지 않는다. 직전 자막을 못 읽으면 잇지 않는다(모르는 것을 같다고 보지 않는다). 지난 실행의 행은 그대로 이력으로 남는다. ⚠ 모델 요약 문구만 달라져도 '다른 내용'이다 — 화면에 나가는 문구를 사람이 본 적이 없으므로. 그래서 재분석하면 사람이 결정했던 발언 중 모델 출력이 달라진 것은 다시 검토 목록에 온다(그 부담이 이 정책의 대가다). 회귀 `ReviewCarryOverTest`·`YoutubeOpinionFlowTest.ReviewCarry`. ⑤ Gemini 는 기존 `GeminiService` 경유(전역 4.5초 제한기 공유) + 동시 1건·일일 호출 상한 60·시간당 요청 10·재료 워밍 보호 시간대 07:20-08:40 — 재료 분석을 밀어내지 않게. 화면 조회로 분석이 트리거되지 않는다. ⑥ 권한: `/api/admin/youtube-opinions/**` 는 SecurityConfig `/api/admin/**` URL 규칙(ADMIN)이 막는다 — `YoutubeOpinionSecurityTest` 가 실제 필터 체인으로 401/403/200 을 고정. 조회 `/api/youtube-opinions/**` 는 로그인 사용자. ⑦ 플래그 `YOUTUBE_OPINION_ENABLED`(기본 false, compose 배선 + 꺼져 있으면 부팅 WARN), 채널은 `YOUTUBE_OPINION_CHANNELS`('채널ID=이름' — **사용자가 고른 채널만**, 모르는 채널을 "신뢰 전문가"로 자동 등록 금지). ⑧ 화면: 종목 상세 '📺 유튜브 참고 의견'(`YoutubeOpinionSection.vue`, 결론 카드와 떨어진 보조 영역) · '오늘' 매수 후보 **카드 밖** 한 줄 + 상세 펼침(후보 요약은 1회 묶음 조회, 5분 재사용) · 관리자 패널(`AdminDashboard` 안 `YoutubeOpinionAdminPanel.vue`). 자막·모델 출력은 전부 평문 렌더링(v-html 금지), 원문 링크는 서버가 만든 `watch?v=ID&t=Ns` 만.

#### §4e.4
