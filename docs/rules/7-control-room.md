#### §7.1

- `/control-room` + `/api/control-room/**`(ADMIN) — 판정 캘린더·KPI·FLAGGED 조회 + AI 크루(에렌/SCOUT/FIREWALL) 5턴 대화. **봇·게이트·가격 경로·신호 합산 코드와 무관하며 그 쪽을 호출만 한다.** 크루에게 **툴을 하나도 주지 않는다**(`CrewLlmClient` 가 `tools` 미전달) — DB·파일·주문에 닿을 경로 자체가 없고, 이 기능의 DB 쓰기는 `crew_session`/`crew_message` 대화 기록뿐이다. 결론은 "액션 제안" 텍스트이고 실행은 사람이 한다. **크루에게 쓰기 툴을 붙이거나 결론을 산식/봇/추천에 편입하지 말 것** — "틀려도 아무 일이 안 일어난다"가 이 화면의 존재 이유다.

#### §7.4

- **불변식**: ① 정상이면 null 을 돌려 **조용하다**(정상에서 시끄러우면 사람이 무시하게 되고 다음 사고도 지나간다) ② 각 규칙은 "무엇을 확인하라"까지 `detail` 에 담는다 ③ 점검 실패는 `dataAvailable=false` — '이상 없음'과 구분(§4c) ④ 크루 컨텍스트에선 KPI·캘린더와 함께 **head 에 들어가 잘리지 않는다**(잘리는 것은 FLAGGED 뿐). 회귀는 `DataAnomalyRulesTest` — 그날 실측 수치로 "이 규칙이 있었다면 울렸을까"를 고정한다.

- 비용 가드 4겹(되돌리지 말 것): **5턴 고정**(자동 루프·재시도 금지, 실패=FAILED+사유) · **동시 1건** · **일일 상한**(초과 시 429, 조용한 스킵 금지) · **컨텍스트 8KB**(초과 시 FLAGGED 를 중요도 낮은 순으로 자르고 "N건 생략" 명시 — 생략을 숨기면 FIREWALL 이 "플래그에 없으니 문제없다"고 판단). 모델 ID 하드코딩 금지(`control-room.crew.model`), 기동 시 `GET /v1/models` 로 실재 확인 후 미존재/키 없음이면 **크루만 DISABLED + 사유 표시**(앱 전체는 정상 기동). ⚠ **그 모델 확인은 페이지네이션을 유한하게 소비해야 한다(2026-09-15 실사고 — 3.5일 API 사망의 진범)**: 원래 `client.models().list().autoPager().forEach(m -> available.add(m.id()))` 였는데, 2026-09-11 구독 게이트웨이(`control-room.crew.api-base=http://claude-gateway:8792`)로 돌리자 그 게이트웨이의 `/v1/models` 가 **커서를 진전시키지 않아 autoPager 가 같은 페이지를 영원히 따라갔다.** 힙 덤프 실측: `"claude-opus-5"`/`"claude-sonnet-5"` 문자열 **3,818만 개 = 힙의 83%(2.2GB)**, 원소 4,672만 개짜리 배열. 약 70분마다 OOM 이 재현됐다. 지금은 `CrewModelAvailability.scanBounded`(순수함수)가 **반복 횟수** 상한 `MAX_MODEL_ITEMS`(500)으로 끊고, 걸리면 WARN 을 남긴다(조용히 끊으면 게이트웨이가 깨진 걸 아무도 모른다 §4c). ⚠ **상한을 "수집된 개수"로 되돌리지 말 것** — 같은 페이지 반복이면 distinct 가 안 늘어 영원히 안 끝난다. ⚠ `VERIFY_TIMEOUT`(20초)은 **요청당**이라 전체 루프를 못 막고, `verifyOnStartup` 은 `@Async` 라 이 루프가 **무음**으로 돈다 — 외부 API 를 순회하는 코드를 새로 붙일 땐 전체 반복에 상한을 걸 것. 회귀 `CrewModelPaginationTest`(고치기 전엔 실패가 아니라 **영원히 멈춘다** — 그래서 타임아웃으로 감쌌다).

#### §7.8

- **"믿고 사도 되나" 게이트(⑦ KPI, 2026-09-16)**: 이 질문의 답을 사람이 적중률 숫자를 눈으로 보고 내리던 것을 규칙으로 옮겼다. **적중률만으론 손익을 모른다** — 맞을 때 얼마 벌고 틀릴 때 얼마 잃는지가 빠져 있고 거래비용도 빠져 있었다. 판정 단일 출처는 순수함수 `TrustGateRules.judge` — **화면에서 다시 계산하지 말 것**(재무 입력층과 같은 규약). 상태는 셋: `COLLECTING`(표본 부족) → `EVALUABLE`(**숫자를 읽을 수 있다는 뜻이지 유리하다는 뜻이 아니다**) → `CONSIDER_EXPANDING`(**모의운용 확대 검토까지 — 실매수 승인이 아니다**). **불변식**: ① **표본 충족은 통과 사유가 아니다** — 30건·10일을 채우면 EVALUABLE 까지만 가고, 거기서 비용 차감 수익 (+)·대조군 우위 > 불확실성 폭·평균 최대낙폭 한도(−10%)가 따로 걸린다.
