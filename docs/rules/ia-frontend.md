#### §ia.8
덧붙임(2026-11-12): 옮긴 뒤 더한 문단이다 — 옛 순서로는 이 절의 마지막 항목.

- **내 사이트 바로가기(`/sites`)는 주식 화면이 아니라 운영 편의 화면이다(2026-11-12)**: 한 서버에 개인 사이트가 여럿 올라가면서 주소를 매번 잊는다는 요청에서 나왔다. 통합 로그인(SSO)은 하지 않기로 했고(사이트마다 로그인은 그대로), 이미 로그인해 쓰는 이 플랫폼 안에 주소 모음 한 화면을 둔다. **'새 주식 화면(라우트) 금지 → 탭/서브탭에 흡수' 규칙은 그대로다** — 이 화면은 종목·시세·추천을 보여 주지 않는 개인 기록 화면(자동차·식단·운동과 같은 종류)이라 그 규칙의 대상이 아니다. 종목·시세·추천 화면을 이 예를 들어 라우트로 만들지 말 것.
  - **목록은 DB 에만(V78 `site_link`, 계정별)**: 화면에서 직접 추가·수정·삭제한다. 저장소가 공개 상태라 주소 목록을 코드·화면 파일(번들은 로그인 없이 내려받힌다)·마이그레이션에 적지 않는다 — `FlywayMigrationTest` 검증 26 이 V78 뒤 행 수 0 을, 프론트 `SiteLinksPage.test.js` 가 화면 소스에 주소가 없음을 본다. 어떤 사이트가 떠 있는지는 로그인한 본인에게만 보인다.
  - **API `/api/site-links` 는 로그인 필수 + 본인 행만**: 권한은 `SecurityConfig` 의 `/api/**` 규칙(공개 목록 `ApiAccessPolicyTest.PUBLIC` 에 넣지 말 것 — 같은 테스트의 `SiteLinks` 묶음이 로그인 없는 요청 401 을 고정한다). 소유권은 `SiteLinkRepository.findByIdAndUserId` 가 지킨다 — 남의 행 id 는 '없음'(404)으로 답하고 그 행은 그대로다(`SiteLinkServiceTest`, 실제 DB).
  - **주소는 http/https 만**: 사용자가 넣은 값이 그대로 `<a href>` 가 되므로 `javascript:`·`data:` 같은 주소가 저장되면 누르는 순간 스크립트가 돈다. 서버(`SiteLinkRules.url` — 호스트 필수, 주소 안 아이디·비밀번호 거절, 공백·제어문자 거절)와 화면(`utils/siteLinks.safeHref`)이 각각 거른다 — 한쪽만 남기지 말 것. 못 믿는 주소는 링크 없이 글자로만 보인다. 이름·설명은 평문(v-html 금지), 새 탭 링크는 `rel="noopener noreferrer"`.
  - 불러오기 실패는 '없음'이 아니라 '불러오지 못했습니다'(§4c). 계정당 100줄 상한(`SiteLinkRules.MAX_LINKS_PER_USER`). 진입은 대시보드(`UserDashboard.vue`)의 '내 사이트' 카드.
