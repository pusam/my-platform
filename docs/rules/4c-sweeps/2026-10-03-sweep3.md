#### §4c.48

- **전수 점검 3차(2026-10-03) — 부호·단위·응답 모양·실패 표시·이름표. 되돌리지 말 것**: ① **`investor_daily_trade` 의 SELL 행 순매수는 음수로 저장된다** — 부호를 다시 붙이지 말고 `StockAnalysisService.signedNet`(SELL → −|v|, BUY → +|v|) 하나로 읽는다(예전엔 SELL 을 한 번 더 뒤집어 순매도한 날을 순매수로 더했다: 삼성전기 외국인 5일 실제 −1,063억 → 화면 +3,282억). 금액은 이미 억원(÷1e8 금지), 기관(`orgn_ntby_tr_pbmn` = 기관 계)에 연기금이 들어 있으니 PENSION 을 기관에 더하지 말 것(`MultiConvictionService` 도 같은 부호 규칙). ② **주식현재가 투자자(FHKST01010900) `output` 은 일자별 행 배열**이고 금액은 **백만원**(÷100 = 억) — 오늘(KST) 행만, 장 마감(15:40) 뒤에만 쓴다("당일 데이터는 장 종료 후 제공", 공식 샘플) — `ScalpingAnalysisService.todayInvestorNetEok`. 단위는 여러 구현이 KIS `utils/marketDataLabels.impactLabel/impactTone` 단일 출처 / AI 시장 예측은 Gemini 실패 시 예측선·확률(30/50/20)을 만들지 않고 실패는 캐시하지 않는다, 프롬프트에 ADR 판단 보류를 'NORMAL' 로, 모든 헤드라인을 '[중립]'으로 넣지 않는다(뉴스 감성은 수집기가 NEUTRAL 고정) / 매매 안전 위젯·봇 카드는 상태를 못 받으면 '상태 확인 실패'(예전 '매매 정상'·'중지됨'), 재개 버튼 숨김 / 봇 성과 거래 0건 창은 PF·승률·극값·낙폭 null(예전 'PF 0.00 · 손실') / 트레이딩 지표 악재 필터 실패는 '확인 불가'(예전 '✅ 매수 가능') / 시장 탭 수급 패널 '상위 10' 합계 실패는 '-'(`topNetSum`)
