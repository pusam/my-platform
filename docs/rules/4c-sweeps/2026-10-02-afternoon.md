# §4c 날짜별 점검 기록 — 같은 날 오후 화면 전수 재점검에서 더 나온 것(2026-10-02)

> 2026-11-11 에 옛 `CLAUDE.md` 에서 글자 그대로 옮긴 경위 원문이다. **지킬 규칙은 `CLAUDE.md` §4c 의 규칙 줄에 있다** — 이 문서는 '왜'를 위한 것이다.
> 번호(예: `§4c.13`)는 옛 `CLAUDE.md` 의 절과 그 절 안 항목 순서다(하위 항목은 `§7.8-2`). 문단 안의 '위·아래 항목'은 이 순서를 가리킨다 — 전체 순서표는 `docs/rules/README.md`.
> 번호 제목 바로 아래의 '정정(날짜): …' 줄은 옮긴 뒤 붙인 것이다(문단은 손대지 않았다).
> 사실이 바뀌면 문단을 고치거나 정정 줄을 붙이고, `CLAUDE.md` 의 같은 번호 규칙 줄도 같이 고친다. `AGENTS.md` 는 `CLAUDE.md` 의 사본이고, 이 문서는 두 쪽이 같이 읽는다.

#### §4c.43

- **같은 날 오후 화면 전수 재점검에서 더 나온 것(2026-10-02)** — 같은 부류(틀린 합계·모르는 값 채우기·검증 안 된 판정): ① 시장 탭 수급 패널의 '외국인 +N억·기관 +N억'은 **순매수 순위 상위 10종목의 합**(늘 +)이었다 — 그 합을 시장 순매수로 보고 "진짜 반등 가능성"/"순매도 — 주의"를 갈라 순매도 분기는 닿지 않았고 3일 연속 종목이 하나만 있어도 늘 '진짜 반등'이었다 → 라벨 '상위 10'·안내 문구, 판정은 사실('외국인 3일+ 연속 순매수 N종목')만, 종목별 '진짜반등/주의' 태그 삭제. ② **섹터 '통신'에 삼성전자·SK하이닉스·삼성전기·LG전자·카카오페이가 들어 있었다** — 반도체 대형주 거래대금이 통신에 한 번 더 잡혀 '통신 8.42조(전체의 35.7%)'·총 23.58조. 통신 = 통신 3사 + NAVER·카카오(GICS 커뮤니케이션 서비스)로 고쳤고, '전체 대비' 분모와 화면 총 거래대금은 **종목 단위로 한 번만 센 값**(`SectorTradingService.applyMarketShare`·`marketTotalTradingValue`, 테마가 겹쳐 비율 합은 100% 를 넘을 수 있다). ⚠ **섹터 평균 등락률은 시장 국면(regime) 입력**이라 이것은 추천 입력 변경이다 — 10/6 표본 시작 전에 배포했다. ③ 해외 시세 고가·저가의 0(Yahoo 가 VIX·미국채 금리에 준다)은 모름(`GlobalFuturesService.zeroAsMissing`, 화면 '-'), 원유 시가·고가·저가 결측을 현재가로 채우지 않고(null, 화면 숨김) 원화 환산은 고정 1,350원 대신 실시간 USD/KRW(`OilPriceService.toKrw`, 모르면 생략). ④ 종합추천 DB 스냅샷 폴백 라벨이 장중 스냅샷에도 '(종가)'였다 → 'MM/dd HH:mm 스냅샷 기준'. ⑤ 승률은 매매 0건이면 '-', 비율이라 부호 없음(예전 '+0.00%'·'+49.12%'). ⑥ 공매도 수집 크론 메서드 이름이 배치 모니터 잡 이름인데 'Balance' 로 남아 있어 `collectShortSellingTrade` 로. ⑦ 관제실 FLAGGED 에서 이미 해소된 R13~R15(9/17)·성장률 배치 4단계(9/29) 항목을 지웠다. 회귀 `SectorTradingShareTest`·`MarketQuoteMissingFieldsTest`·프론트 `screenSweep3.test.js`·`marketDataLabels.test.js`(marketTotalOf).
